# finance-portfolio 仕様書

個人の高配当株ポートフォリオを自動分析・レポート出力するシステム。

---

## フォルダ構成

```
.company/finance-portfolio/
├── README.md         ← この仕様書
├── analyze.py        ← 分析スクリプト（メイン）
├── data/             ← SBIからエクスポートしたCSVを置く場所
│   └── MMDD名前.csv
└── reports/          ← 自動生成されたレポートの保存先
    └── YYYY-MM-DD-report.md
```

---

## 使い方

1. SBI証券からCSVをエクスポートして `data/` フォルダに入れる
2. Claude Codeに「実行してください」と伝える（または手動で下記コマンド）

```bash
cd /mnt/c/cc-company/.company/finance-portfolio
python3 analyze.py
```

`data/` 内の最新CSVを自動で読み込み、`reports/YYYY-MM-DD-report.md` を生成する。

---

## データソース

### 入力：SBI証券のCSV
- SBI証券のポートフォリオ一覧画面からエクスポートしたCSV
- 文字コード：Shift-JIS（スクリプトが自動変換）
- `data/` フォルダに置くだけでOK（ファイル名は何でも可）
- 最終更新日時が最新のCSVを自動で使用

### 外部データ取得
| データ | 取得先 | 対象 |
|--------|--------|------|
| 配当履歴・増配率 | minkabu.jp | 日本株（4年分の実績＋来期予想） |
| 業種（セクター） | minkabu.jp | 日本株（33業種分類を自動取得） |
| SCHD配当履歴 | Yahoo Finance API | SBI米国高配当株ファンド（USD建て） |
| 米国株配当・株価 | Yahoo Finance API | 購入候補ウォッチリスト銘柄 |
| USD/JPY レート | Yahoo Finance API | 米国株の円換算・実質利回り計算 |

## 分析設定

| 設定値 | 内容 | デフォルト |
|--------|------|-----------|
| `DIV_YIELD_THRESHOLD` | 理想配当利回り基準 | 3.5% |
| `DIV_GROWTH_THRESHOLD` | 理想増配率CAGR基準 | 10% |
| `SECTOR_WARNING_THRESHOLD` | セクター集中警告閾値 | 30% |
| `TARGET_JP_RATIO` | 日本株目標比率 | 50% |
| `TARGET_US_RATIO` | 米国株目標比率 | 50% |
| `US_WITHHOLDING_NISA` | NISA口座の米国源泉税 | 10% |
| `US_WITHHOLDING_TAXABLE` | 特定口座の米国源泉税 | 10% |
| `JP_TAX_TAXABLE` | 特定口座の日本配当課税 | 20.315% |

## レポートの内容

### 既存分析

#### 1. サマリー
- 総評価額・含み損益（ポートフォリオ全体）

#### 2. 銘柄別損益
- 全銘柄の含み損益率順ソート
- 口座種別（NISA / 特定）を表示

#### 3. 配当収入・利回り
- 配当がある銘柄のみ対象（無配銘柄・インデックスファンドは除外）
- 年間配当収入（円）・配当利回りを銘柄ごとに表示

#### 4. ETF枠（SBI米国高配当株式ファンド）
- SCHD連動ファンドの評価額・含み損益・5年CAGR

#### 5. 積立枠（インデックスファンド）
- S&P500・オルカンの評価額・含み損益（配当計算対象外）

#### 6. 増配率（過去4年CAGR）
- 全銘柄の増配率を横軸年度の表で表示
- 予想値は「(予)」マークで区別
- 単純平均・加重平均（評価額ベース）を表示

#### 7. 増配率ランキング Top10・要注意銘柄（減配傾向）

---

### ポートフォリオ分析・提案（追加済み）

#### 分析1. 資産配分
- 日本株（個別）vs 米国（投信）の現在比率を表示
- 目標50:50との乖離を検出し、調整すべき金額を表示

#### 分析2. セクター分析
- minkabuから業種を自動取得（33業種分類）
- セクター別評価額・比率をテキストバーグラフで可視化
- 単一セクターが30%超で⚠️警告
- 金融系（銀行・保険・証券・その他金融）を合算して集中リスク判定

#### 分析3. 銘柄集中度 Top10
- 1銘柄で評価額の10%超を占める場合に⚠️警告

#### 分析4. 投資スタイル適合度マトリクス
保有銘柄を利回り・増配率で4分類して表示：
- 🌟 理想ゾーン（利回り3.5%＋ × 増配10%＋）
- 💰 安定配当ゾーン（高利回り・増配は控えめ）
- 📈 成長型ゾーン（低利回り・高増配）
- ⚠️ 要検討ゾーン（両方基準以下）

#### 分析5. 要注意銘柄（詳細）
- 減配傾向・含み損の組み合わせで対応方針を自動判定
- 減配＋含み損 → 売却検討 / 減配のみ → 監視強化 / 含み損のみ → 様子見

#### 分析6. 総合提案コメント
- 上記分析を踏まえた具体的なアクション提案を自動生成

#### 分析7. 日本株 購入候補提案
未保有・不足セクターを優先し、ウォッチリスト銘柄の配当・増配データをリアルタイム取得して提案：
- 🌟 最優先候補（利回り3.5%＋ × 増配10%＋）
- 💰 高利回り候補
- 📈 高増配候補
- 📌 セクター分散目的候補

**現在のウォッチリスト対象セクター：**
医薬品 / 電気機器 / 機械 / 小売業 / 陸運業 / 電気・ガス業 / 海運業 / 化学 / 食料品 / 銀行業 / 不動産業 / その他金融業

#### 分析8. 米国株 購入候補提案
Yahoo Finance APIから株価・配当データをリアルタイム取得し、**源泉税控除後の実質利回り**を表示：
- NISA口座：米国源泉税10%のみ控除（表面利回り × 0.90）
- 特定口座：米国10% + 日本20.315% = 合計約28.3%控除（表面利回り × 0.717）
- 当年の途中配当データは除外し、前年の確定値で計算

**現在のウォッチリスト対象セクター：**
医薬品 / 生活必需品 / エネルギー / 通信 / REIT / IT・工業 / 金融

## 注意事項

- minkabu のスクレイピングは銘柄数が多いと数分かかる（ウォッチリスト含め約5〜8分）
- SCHD の増配率は USD 建て（円換算ではない）
- 増配率の「調整後」値を使用（株式分割を考慮したもの）
- SBI新生銀行・ソニーFGは配当データなし（minkabuに掲載なし）
- 米国株の配当・株価はYahoo Finance APIから取得（市場時間外は前日終値）
- USD/JPY レートは実行時点の値を使用
