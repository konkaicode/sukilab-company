# finance-portfolio 仕様書

個人の高配当株ポートフォリオを自動分析・レポート出力するシステム。

---

## フォルダ構成

```
.company/finance-portfolio/
├── README.md         ← この仕様書
├── analyze.py        ← 分析スクリプト（メイン）
├── watch.sh          ← ファイル監視スクリプト（自動実行用）
├── watch.log         ← 自動実行のログ
├── data/             ← SBIからエクスポートしたCSVを置く場所
│   └── MMDD名前.csv
└── reports/          ← 自動生成されたレポートの保存先
    └── YYYY-MM-DD-report.md
```

---

## データソース

### 入力：SBI証券のCSV
- SBI証券のポートフォリオ一覧画面からエクスポートしたCSV
- 文字コード：Shift-JIS（スクリプトが自動変換）
- `data/` フォルダに置くだけでOK（ファイル名は何でも可）
- 最終更新日時が最新のCSVを自動で使用

### 外部データ取得
| データ | 取得先 | 対象 |
|--------|--------|------|
| 配当履歴・増配率 | minkabu.jp | 日本株（4年分の実績＋来期予想） |
| SCHD配当履歴 | Yahoo Finance API | SBI米国高配当株ファンド（USD建て） |

---

## レポートの内容

### 1. サマリー
- 総評価額・含み損益（ポートフォリオ全体）

### 2. 銘柄別損益
- 全銘柄の含み損益率順ソート
- 口座種別（NISA / 特定）を表示

### 3. 配当収入・利回り
- 配当がある銘柄のみ対象（無配銘柄・インデックスファンドは除外）
- NISA・特定口座を別行で表示
- 年間配当収入（円）・配当利回りを銘柄ごとに表示
- 配当あり銘柄全体の利回りを表示

### 4. ETF枠（SBI米国高配当株式ファンド）
- SCHD連動ファンドの評価額・含み損益
- 5年CAGR（USD建て）・配当履歴を表示

### 5. 積立枠（インデックスファンド）
- S&P500・オルカンの評価額・含み損益
- 配当計算対象外として別枠で管理

### 6. 増配率（過去4年CAGR）
- 全銘柄の増配率を横軸年度の表で表示
- 予想値は「(予)」マークで区別
- 単純平均・加重平均（評価額ベース）を表示

### 7. 増配率ランキング Top10

### 8. 要注意銘柄（減配傾向）

## 自動実行の仕組み

```
WSL起動
  ↓
watch.sh が起動（@reboot でcrontab登録済み）
  ↓
30秒ごとに data/ の最新CSVと reports/ の最新レポートのタイムスタンプを比較
  ↓
CSVの方が新しければ analyze.py を実行
  ↓
reports/YYYY-MM-DD-report.md を生成・上書き
```

### 手動実行する場合
```bash
cd /mnt/c/cc-company/.company/finance-portfolio
python3 analyze.py
```

### 監視スクリプトをバックグラウンドで手動起動する場合
```bash
bash /mnt/c/cc-company/.company/finance-portfolio/watch.sh &
```

---

## 注意事項

- WSLが起動していないと watch.sh も止まる（PC再起動後はWSLを開く必要あり）
- minkabu のスクレイピングは銘柄数が多いと1〜2分かかる
- SCHD の増配率は USD 建て（円換算ではない）
- 増配率の「調整後」値を使用（株式分割を考慮したもの）
  - 例：日本製鉄は2024年に1→5分割。表示は分割後の32円/株ベース
- SBI新生銀行・ソニーFGは配当データなし（minkabuに掲載なし）
