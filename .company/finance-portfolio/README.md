# finance-portfolio

SBI証券のCSVから高配当株ポートフォリオを自動分析・レポート出力するシステム。

---

## フォルダ構成

```
finance-portfolio/
├── README.md               ← この仕様書
├── analyze.py              ← 分析スクリプト（メイン）
├── config/
│   └── sector_map.yaml     ← GICSセクター 英語→日本語 対応表
├── data/                   ← SBIからエクスポートしたCSVを置く場所
│   └── MMDD*.csv
└── reports/                ← 自動生成されたレポートの保存先
    ├── YYYY-MM-DD-portfolio.md       ← ポートフォリオレポート
    └── YYYY-MM-DD-recommendations.md ← 購入提案レポート
```

---

## 使い方

1. SBI証券からCSVをエクスポートして `data/` フォルダに入れる
2. 以下のコマンドを実行する

```bash
cd /mnt/c/cc-company/.company/finance-portfolio
python3 analyze.py
```

3. ポートフォリオレポートが自動出力される
4. `購入提案レポートも作成しますか？ [y/N]` と表示されるので、必要なら `y` を入力する

### レポートのファイル構成

| ファイル | 内容 | 生成タイミング |
|---------|------|--------------|
| `YYYY-MM-DD-portfolio.md` | 保有銘柄の分析・現状把握 | 毎回自動生成 |
| `YYYY-MM-DD-recommendations.md` | 購入候補の提案 | `y` 入力時のみ（約5〜10分） |

両ファイルの先頭・末尾に相互リンクが貼られており、行き来できる。

## データソース

### 入力：SBI証券のCSV
- SBI証券のポートフォリオ画面からエクスポートしたCSV
- 文字コード：Shift-JIS（スクリプトが自動変換）
- `data/` フォルダに置くだけでOK（ファイル名は任意）
- 最終更新日時が最新のCSVを自動で使用

### 外部データ取得（yfinance）

すべての株価・配当データを **yfinance ライブラリ（v1.2.0以上）** 経由で取得する。
minkabu等のスクレイピングは使用しない。

| データ | 取得方法 | 対象 |
|--------|---------|------|
| 配当履歴・増配率CAGR | `yf.Ticker(code).dividends` | 保有日本株・購入候補 |
| 現在値 | `yf.Ticker(code).fast_info` | 保有日本株・購入候補 |
| セクター（GICS） | `yf.Ticker(code).info["sector"]` | 保有日本株・購入候補 |
| PER / PBR / ROE / 売上成長率 | `yf.Ticker(code).info` | 購入候補のバリュースコア計算 |
| 東証全銘柄スクリーニング | `yf.EquityQuery` + `yf.screen` | 購入候補の母集団取得 |
| SCHD配当履歴 | Yahoo Finance API（直接） | SBI米国高配当株ファンド（USD建て） |
| 米国株配当・株価 | Yahoo Finance API（直接） | 米国購入候補ウォッチリスト |
| USD/JPY レート | Yahoo Finance API（直接） | 米国株の円換算 |

### セクター分類（GICS）

`config/sector_map.yaml` で GICS英語名→日本語訳 を管理している。
レポートでは `Financial Services（金融サービス）` の形式で表示する。

```yaml
Financial Services: 金融サービス
Technology: テクノロジー
Healthcare: ヘルスケア
# ...
```

## 分析設定

`analyze.py` 冒頭の定数で変更できる。

| 定数 | 内容 | デフォルト |
|------|------|-----------|
| `DIV_YIELD_THRESHOLD` | 理想配当利回り基準 | 3.5% |
| `DIV_GROWTH_THRESHOLD` | 理想増配率CAGR基準 | 10% |
| `SECTOR_WARNING_THRESHOLD` | セクター集中警告閾値 | 30% |
| `TARGET_JP_RATIO` | 日本株目標比率 | 50% |
| `TARGET_US_RATIO` | 米国株目標比率 | 50% |
| `SCREEN_SIZE` | 東証スクリーニング最大取得件数 | 100件 |
| `SCREEN_MIN_YIELD` | スクリーニング最低配当利回り | 1.5% |
| `US_WITHHOLDING_NISA` | NISA口座の米国源泉税 | 10% |
| `US_WITHHOLDING_TAXABLE` | 特定口座の米国源泉税 | 10% |
| `JP_TAX_TAXABLE` | 特定口座の日本配当課税 | 20.315% |

## ポートフォリオレポートの内容

### サマリー
- 総評価額・含み損益（ポートフォリオ全体）

### 銘柄別損益
- 全銘柄の含み損益率順ソート
- 口座種別（NISA / 特定）を表示

### 配当収入・利回り
- 配当がある銘柄のみ対象
- 年間配当収入（円）・配当利回りを銘柄ごとに表示

### ETF枠 / 積立枠
- SBI米国高配当株式ファンド（SCHD連動）：5年CAGR・配当履歴
- インデックスファンド：評価額・含み損益（配当計算対象外）

### 増配率（過去4〜5年CAGR）
- 年ごとの配当額推移を横軸で表示
- 単純平均・加重平均（評価額ベース）を表示
- ランキングTop10 / 減配傾向銘柄を別表で表示

### ポートフォリオ分析
| セクション | 内容 |
|-----------|------|
| 1. 資産配分 | 日本株 vs 米国（投信）の比率。目標50:50との乖離を検出 |
| 2. セクター分析 | GICS分類でセクター別比率をバーグラフ表示。30%超で警告 |
| 3. 銘柄集中度 | 1銘柄10%超で警告 |
| 4. 投資スタイルマトリクス | 利回り×増配率で4分類（理想 / 安定配当 / 成長型 / 要検討） |
| 5. 要注意銘柄 | 減配傾向・含み損の組み合わせで対応方針を自動判定 |
| 6. 総合提案 | 上記分析を踏まえたアクション提案を自動生成 |

## 購入提案レポートの内容

### バリュースコア（100点満点）

購入候補銘柄を以下の5指標で採点し、スコア降順でランキングする。

| 指標 | 配点 | 高得点条件 |
|------|------|-----------|
| PER | 25点 | 低いほど高得点（10倍未満で満点） |
| PBR | 25点 | 低いほど高得点（0.8倍未満で満点） |
| 配当利回り | 20点 | 高いほど高得点（5%以上で満点） |
| ROE | 15点 | 高いほど高得点（20%以上で満点） |
| 売上成長率 | 15点 | 高いほど高得点（15%以上で満点） |

### 1. 日本株購入候補

`yf.EquityQuery` で東証全銘柄をスクリーニング（配当利回り1.5%以上・最大100件）し、
保有済み銘柄を除外したうえでバリュースコア順に提案する。

4カテゴリで分類して表示：
- 🌟 最優先候補（利回り3.5%以上 × 増配率10%以上）
- 💰 高利回り候補（増配率は基準以下）
- 📈 高増配候補（利回りは基準以下・将来性あり）
- 📌 セクター分散目的候補

### 2. 米国株購入候補

固定ウォッチリスト（18銘柄）から株価・配当データをリアルタイム取得し、
**源泉税控除後の実質利回り**を表示する。

| 口座 | 控除 |
|------|------|
| NISA口座 | 米国源泉税10%のみ（日本課税なし） |
| 特定口座 | 米国10% + 日本20.315% = 合計約28.3% |

**ウォッチリスト対象セクター：** 医薬品 / 生活必需品 / エネルギー / 通信 / REIT / IT・工業 / 金融

## 配当データの補正ロジック

日本株は年2回払い（中間・期末）のため、期末配当が翌年1月に計上されるケースがある。
当年のデータが前年比75%未満の場合は「途中データ」と判定して除外する。

```
例：積水ハウス（1928）
  期中配当（7月）:72円 → 2025年計上
  期末配当（1月）:72円 → 2026年計上（翌年扱い）
  → 2026年集計で72円のみになるため、75%閾値で除外し前年確定値を使用
```

## 注意事項

- yfinance の配当データはYahoo Finance準拠。銘柄によっては欠損することがある
- SCHD・米国株の増配率はUSD建て（円換算ではない）
- 購入提案レポートの生成は東証スクリーニング + 各銘柄のAPI取得で約5〜10分かかる
- 株価・配当は実行時点の値を使用（市場時間外は前日終値）
- 上記はすべて参考情報。最終的な投資判断は自己責任で行うこと
