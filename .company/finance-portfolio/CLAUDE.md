# ファイナンス部署

## 役割
SBI証券の保有ポートフォリオを自動分析し、配当・セクター・購入候補のレポートを生成する。
高配当株投資の現状把握と、次の購入判断をサポートする。

## フォルダ構成
- `analyze.py` — 分析スクリプト（メイン）
- `config/sector_map.yaml` — GICSセクター 英語→日本語 対応表
- `data/` — SBIからエクスポートしたCSVを置く場所
- `reports/` — 自動生成されたレポートの保存先

## レポートの種類
| ファイル | 内容 | 生成タイミング |
|---------|------|--------------|
| `YYYY-MM-DD-portfolio.md` | 保有銘柄の分析・現状把握 | 毎回自動生成 |
| `YYYY-MM-DD-recommendations.md` | 購入候補の提案 | `y` 入力時のみ（約5〜10分） |

両ファイルの先頭・末尾に相互リンクあり。

## 実行方法

```bash
cd /mnt/c/cc-company/.company/finance-portfolio
python3 analyze.py
```

1. `data/` 内の最新CSVを自動読み込み
2. ポートフォリオレポートを出力
3. `購入提案レポートも作成しますか？ [y/N]` → `y` で購入提案も生成

## データソース
- **株価・配当・セクター**: yfinance（v1.2.0以上）
- **東証スクリーニング**: `yf.EquityQuery` + `yf.screen`（配当利回り1.5%以上・最大100件）
- **米国株・SCHD**: Yahoo Finance API 直接
- **USD/JPY**: Yahoo Finance API 直接
- minkabu等のスクレイピングは使用しない

## スコアリング（購入候補の採点基準）

### バリュースコア（参考値）
PER(25点) + PBR(25点) + 配当利回り(20点) + ROE(15点) + 売上成長率(15点) = 100点満点

### 安定性スコア（主軸）
連続非減配年数(0-30点) + コロナ禍（2020年）サバイバル(0-20点) = 50点満点
- 20期以上: 30点 / 15-19期: 26点 / 10-14期: 22点 / 7-9期: 16点 / 5-6期: 11点 / 3-4期: 6点
- COVID2020年に減配なし: +20点ボーナス

### 総合スコア（購入候補のソート順）
**連続非減配 > 利回り > 増配率** の重みで算出
安定性(0-50点)×3 ＋ 利回り(0-20点)×2 ＋ 増配率(0-15点)×1 = 最大205点
