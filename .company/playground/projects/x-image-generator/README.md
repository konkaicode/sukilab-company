# X発信用 画像生成プロジェクト

## 目的
X（Twitter）投稿に使える画像を生成・管理できる仕組みを作る。
2つのアプローチを実験し、使い勝手・品質・速度を比較する。

---

## アプローチ比較

| 観点 | A: HTML Canvas生成 | B: Figma連携 |
|------|-------------------|-------------|
| 速度 | ◎ コードで即生成 | △ Figma操作が必要 |
| クオリティ | ○ CSSレベル | ◎ デザイナー品質 |
| 再現性 | ◎ 毎回同じ出力 | ◎ コンポーネント管理 |
| バリエーション | ○ パラメータ変更で量産 | ◎ バリアント機能 |
| 初期コスト | ○ テンプレート作成のみ | △ Figmaセットアップ |
| 運用コスト | ◎ ほぼゼロ | ○ Figmaファイル管理 |
| エクスポート | △ puppeteer等が必要 | ◎ ネイティブエクスポート |
| MCP対応 | - | ○ Figma MCPで自動化可能 |

---

## アプローチA: HTML Canvas / PNG生成

### 概要
HTMLテンプレートをブラウザで開き、スクリーンショットまたはCanvas APIでPNGに書き出す。

### 想定フロー
1. `approach-a-canvas/template.html` でデザインを作る
2. ブラウザで開いてスクショ、またはPuppeteerでPNG出力
3. テキスト・色をパラメータ化して量産

### 課題
- [ ] テンプレートHTMLの設計
- [ ] PNG書き出し方法の検討（スクショ手動 or Puppeteer自動化）
- [ ] Xの推奨サイズ確認（OGP: 1200×630 / 正方形: 1080×1080）

### ファイル
- `approach-a-canvas/` - HTML/CSSテンプレート置き場

---

## アプローチB: Figma連携

### 概要
Figmaでデザインテンプレートを作成し、Figma MCPまたはFigma APIで自動化。
テキスト差し替え → エクスポートまでを自動化できる可能性あり。

### 想定フロー
1. Figmaでテンプレートコンポーネントを作成
2. Figma MCP（`use_figma`）でテキスト・変数を差し替え
3. エクスポートしてX投稿に使用

### 課題
- [ ] Figmaテンプレートの設計
- [ ] Figma MCPの接続確認
- [ ] 変数（テキスト・色）の差し替えフロー検証
- [ ] エクスポート自動化の検討

### ファイル
- `approach-b-figma/` - Figmaリンク・メモ置き場

---

## Xの画像サイズ仕様

| 用途 | 推奨サイズ | 比率 |
|------|----------|------|
| 通常ツイート画像 | 1200 × 675 px | 16:9 |
| 正方形 | 1080 × 1080 px | 1:1 |
| OGP / カード | 1200 × 630 px | 1.91:1 |
| ヘッダー | 1500 × 500 px | 3:1 |
