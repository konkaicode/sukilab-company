## フォルダ構成
- `revenue.csv` — 全売上データ（Notionと同期）
- `sync.md` — 最終同期情報（日時・件数）
- `reports/` — 月次レポートなど

## 同期ルール（リスク対策込み）

### 同期方法：全件洗い替え
- 追記ではなく **毎回 revenue.csv を全件上書き**する
- 削除・修正もNotionが正として反映される

### 同期手順
1. Notionの収益ページ配下を page_size=25 で検索（複数回）
2. 全レコードのプロパティを取得
3. revenue.csv を新データで上書き
4. sync.md に同期日時・取得件数を記録
5. 「Notionの表示件数と一致しているか？」を確認してこんちゃんに報告

### 同期タイミング
- **手動トリガー**: こんちゃんが「売上同期して」と言ったときのみ実行する
- 自動同期は行わない

### 同期後の確認レポート
```
✅ 同期完了: YYYY-MM-DD HH:MM
   取得件数: XX件（前回比: +N件）
   未請求: XX件 / ¥XXX,XXX
   今月売上: ¥XXX,XXX
```

## 分析コマンド例
- 「今月の売上は？」 → revenue.csv から当月集計
- 「未請求一覧を出して」 → 進捗状況=未請求でフィルタ
- 「クライアント別売上は？」 → クライアントでグループ集計
- 「目標まであといくら？」 → 当月売上 vs 目標¥500,000
