## データソース
- **一次ソース**: Notion 収益DB

- **ローカルミラー**: `revenue.csv`（Notionから同期）

## 同期ツール
- **使用ツール**: `ntn`（Notion 公式 CLI）← 2026-03-22 より変更
- **旧ツール**: Notion MCP（廃止。セマンティック検索の取得漏れ問題のため）
- **認証**: `NOTION_API_TOKEN`（`~/.bashrc` に設定済み）

## フォルダ構成
- `revenue.csv` — 全売上データ（Notionと同期）
- `sync.md` — 最終同期情報（日時・件数）
- `reports/` — 月次レポートなど

## 同期ルール（リスク対策込み）

### 同期方法：全件洗い替え
- 追記ではなく **毎回 revenue.csv を全件上書き**する
- 削除・修正もNotionが正として反映される

### 同期手順
1. `ntn api v1/data_sources/e2b61a38-4509-4e48-a938-8536c35ccc6b/query -d '{"page_size":100}'` で全件取得
2. 全レコードのプロパティを取得
3. revenue.csv を新データで上書き
4. sync.md に同期日時・取得件数を記録
5. **レポートを自動更新**する → `reports/YYYY-MM-DD-report.md` を新規作成
6. 「Notionの表示件数と一致しているか？」を確認してこんちゃんに報告

### 同期タイミング
- **手動トリガー**: こんちゃんが「売上同期して」と言ったときのみ実行する
- 自動同期は行わない

### 同期後の確認レポート
```
✅ 同期完了: YYYY-MM-DD HH:MM
   取得件数: XX件（前回比: +N件）
   未請求: XX件 / ¥XXX,XXX
   今月売上: ¥XXX,XXX
```

## CSVフォーマット
```csv
notion_id,名称,クライアント,仕事内容,単価,個,発生日,請求日,進捗状況,freee
```

## 分析コマンド例
- 「今月の売上は？」 → revenue.csv から当月集計
- 「未請求一覧を出して」 → 進捗状況=未請求でフィルタ
- 「クライアント別売上は？」 → クライアントでグループ集計
- 「目標まであといくら？」 → 当月売上 vs 目標¥500,000

## 目標
- 月収目標: **¥500,000**（2026年）
- 年収目標: **¥6,000,000**（2026年）

## レポート構成
同期後に以下のセクションを含むレポートを自動生成する：
1. 年間目標の進捗（累計売上・達成率・残り必要月平均）
2. 今月の状況（確定・見込み・目標比）
3. 月別売上推移
4. クライアント別売上・依存リスク（30%超で⚠️・40%超で🔴）
5. 仕事内容別売上
6. 進捗状況サマリー
7. 請求済み入金待ち（経過日数・催促判断）
8. 未請求一覧（freee登録状況付き）
9. freee未登録リスト
10. 全期間合計
