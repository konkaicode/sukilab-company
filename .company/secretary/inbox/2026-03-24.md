## 💡 Freee MCP × 経理部署 活用アイデア
*追記: 2026-03-24 / freee MCP 導入記念メモ*

### 背景
- 2026-03-24 に freee MCP を導入
- 現在の経理部署は「Notion → revenue.csv → レポート生成」のフロー
- freee MCP でリアルタイムに請求書・入金データを取得できるようになった

---

### アイデア一覧

#### 🔵 すぐできそう（小さく試せる）

1. **入金期限アラート**
   - freee MCP で `payment_status: unsettled` かつ `payment_date` が近い請求書を検出
   - `/company` 起動時に「3日以内に入金期限の請求書があります」と自動通知
   - 今日確認した2月分5件（3/31期限）がまさにこのケース

2. **freee未登録チェックの自動化**
   - 経理レポートの項目10「freee未登録リスト」を、Notion（revenue.csv）× freee MCP で自動照合
   - NotionにあってFreeeにない案件を自動検出 → 登録漏れゼロへ

3. **月次レポートのデータ強化**
   - 今は revenue.csv（Notion）だけでレポート生成
   - freee MCP の請求書データ（税込・税抜・源泉徴収）も加えて精度UP
   - 特に源泉徴収が発生するクライアント（Tech Droneなど）の手取り管理に使える

#### 🟡 少し設計が必要なもの

4. **Notion ↔ Freee 売上照合レポート**
   - revenue.csv と freee の請求書一覧を突き合わせ
   - 「Notionにあって請求書未発行」「Freeeにあって請求書は出たが入金未確認」など状態を可視化
   - 現在の経理レポートに「freee照合セクション」として追加

5. **入金確認の半自動化**
   - 月末に「入金期限が当月の請求書一覧」を freee MCP から取得
   - 入金済み（settled）/ 未入金（unsettled）の一覧を自動生成
   - 催促が必要なクライアントを色分けして表示

#### 🔴 将来的な大きな構想

6. **Freeeをマスターデータ化（Notion二重管理の解消）**
   - 現在：Notion で売上管理 → revenue.csv に同期
   - 将来：freee を一次ソースにして、請求書作成〜入金確認まで全部freeeで完結
   - 経理部署のデータソースを Notion から freee に移行

7. **請求書ドラフト自動生成**
   - 案件完了時に「freeeで請求書作って」と言うだけで自動作成
   - freee MCP の POST /invoices を活用
   - Notionの案件情報から金額・クライアント・件名を自動入力
