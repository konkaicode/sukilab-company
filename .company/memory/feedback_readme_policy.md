---
name: README作成・更新ポリシー
description: 新しいプロジェクト・ツール作成時のREADME必須化と、開発中の都度更新ルール
type: feedback
---

新しいプロジェクト・スクリプト・ツールを作成したときは、必ずREADME（説明書）を作成する。

**Why:** こんちゃんが後から見返したときに何のために作ったのか・どう使うのかがわかるようにしておきたい。finance-portfolioでの実例から明文化。

**How to apply:**
- 新しいフォルダ・プロジェクトを作り始めたタイミングで README.md を作成する
- 開発・機能追加のたびに README を都度更新する（後まわしにしない）
- 内容の目安：使い方・フォルダ構成・データソース・機能一覧・注意事項
