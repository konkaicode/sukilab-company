# スキル・対応範囲・条件

> 応募文の「対応スキル」「単価」「稼働」パートの元データ。
> ②自動探索のマッチング判定基準としても再利用する（募集が条件に合うか判定）。

## 対応スキル

### コーディング
- HTML / CSS / SCSS（レスポンシブ対応、**ピクセルパーフェクト**）
- JavaScript / jQuery
- アニメーション：**GSAP / ScrollTrigger / Lenis（慣性スクロール）**
- 簡易 React

### CMS・バックエンド
- **WordPress**（メイン）：ACF / オリジナルテーマ / カスタム投稿タイプ
- WordPressリニューアル：functions.php リダイレクト設定、エクスポートでの記事移管
- **Shopify / Liquid**（サブ。まちたけさんのもとで修行中）
- PHP

### デザイン・実装フロー
- Figma / Adobe XD / Photoshop からの実装
- デザインからの一気通貫対応も可（Uno Wellness 等）
- Git / GitHub / Sourcetree、Gulp
- SEO対策 / WEBマーケティング / コピーライティング

## 対応可能な案件タイプ

- LP（静的・WordPress・Shopify）
- コーポレートサイト
- WordPress構築・リニューアル
- ECサイト（Shopify）
- サイト運営・更新作業

## 単価感

| 案件 | 目安 |
|------|------|
| LP1枚（PC/SPレスポンシブ・問い合わせフォーム込み） | 80,000円＋税 |
| WordPress構築 | ボリュームにより応相談（参考：市場感 20〜30万円/月規模） |

- 継続・関係性・ボリュームに応じて柔軟対応
- 「提示単価で問題ない」と返すことも多い（関係構築優先のとき）

## 稼働条件

- **週20〜30時間程度**（繁忙期はそれ以上も対応可）
- 平日・休日問わず柔軟（通信制大学・夜型）
- フルリモート対応、オンラインMTG（Zoom 音声のみ可）対応
- 報連相：相手の要望に合わせた頻度。スプレッドシート管理も対応
- コードFB：歓迎（品質向上に前向き）

## 強み（条件面）

- 即稼働可能なタイミングが多い（リソースに余裕があると明記して訴求）
- 納期厳守・早めの報連相・長期志向
- お試し・スポット依頼も歓迎

## NG・苦手・注意（マッチング除外の参考）

- 単純作業・繰り返し作業の大量受注は不向き（テロップ入れ等で離脱経験あり）
- 「替えがきく」だけの作業は熱量が続きにくい
- アニメーション・three.js 系のフル実装はまだ発展途上（GSAP範囲は得意）
- 朝型前提・早朝稼働の案件は相性が悪い（夜型）
